kind: added
summary: AdminPanelHeader gains a collapsible band, so the description, status, search and filters above a table fold away with one Hide controls button while the title, actions and applied-filter chips stay
---

`AdminPanelHeader` takes a `summary` slot (status tiles or a status line between `detail` and `toolbar`) and a `collapsible` prop (`storageKey`, `collapsedSummary`, `activeCount`, `defaultCollapsed`). The title row gains a real button that reads "Hide controls" or "Show controls" with a chevron, `aria-expanded` and `aria-controls`; the collapsed region is `hidden`, so it leaves the tab order, and focus stays on the toggle. Collapsed, the title row shows `collapsedSummary` inline from 64rem and on its own line below it. The band starts collapsed below 64rem wide or 45rem tall and expanded above, and the viewer's choice is kept in `localStorage` under `admin-kit:header:<storageKey>:<regular|compact>`, one key per width class. Storage that throws is tolerated, and the first client render already reads the stored state, so nothing shifts on first paint. `AdminFilterChip` is the removable applied-filter chip for the summary line; removing one hands focus back to the toggle. `AdminWorkspace` takes the same `collapsible` prop and then renders its framed header through `AdminPanelHeader`. `EventsPanel`, `UsersPanel`, `ApiKeysPanel` and `OperationalJobsPanel` take `headerCollapsible` and `headerSummary` (`OperationalJobsPanel` also takes `headerPresentation` and now draws its title band with `AdminPanelHeader`), so one band covers kit panels and host pages. `EventsPanel` moves its search and filters into the header toolbar, puts Refresh in the title row as a secondary button, and shows applied filters as chips while collapsed.

Panel text fixes ride with it. The `EventsPanel` table's Event cell shows the action and "returned N" from `metadata.status` (the message when there is no status) instead of printing the request path twice; Resource wraps to two lines with its full value in a `title`, and the time no longer breaks inside the clock value. Search fields keep room for their placeholder, `AdminActionButton` keeps a gap between icon and label, the Details column header uses the same heading structure as the others, and long panel titles wrap instead of running off the page.
